How it works

  1. 01

    Form → JSON

    The browser checks the fields, then sends them to the API with fetch.

  2. 02

    Salt + scrypt

    Express hashes the password with Node's built-in crypto.scrypt and a random salt.

  3. 03

    MySQL

    Only the hash goes into the users table. Queries use placeholders, so no SQL injection.
